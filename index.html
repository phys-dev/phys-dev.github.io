Физика и код

Учебные пособия по физике ускорителей, школьной физике и программированию в научных исследованиях. Все пособия открыты, собираются автоматически из репозиториев и читаются в браузере без установки чего-либо.

Физика ускорителей

Три пособия по курсам магистратуры: каждый вопрос разобран в отдельной тетради с выводом формул в СГС и расчётом на Python.

  • Коллективные эффекты в ускорителях

    Кильватерные поля и импедансы, неустойчивости в моделях макрочастиц, кинетическое описание через уравнение Власова. Семнадцать вопросов.

    исходникиcollective-effects-bookJupyter Book
  • Нелинейная динамика в ускорителях

    Параметрический резонанс и адиабатические инварианты, сдвиги бетатронных частот, компенсация эффектов встречи, ионное облако вдоль поезда сгустков. Восемь задач.

    исходникиnonlinear-dynamics-bookJupyter Book
  • Электрическая прочность

    Пробой в вакууме, газах и твёрдых диэлектриках, тёмные токи, мультипактор, механизмы Таунсенда и стримера, инженерные критерии изоляции. Восемь тем.

    исходникиelectrical-strength-bookJupyter Book

Школьная физика

Интерактивные уроки для основной школы по учебнику И. М. Перышкина и задачнику А. Е. Марона.

  • Базовая школьная физика

    Курс 7–9 классов. Каждый урок содержит теорию, модель, которой можно управлять прямо на странице, опыт с измерениями, задачи с разбором и домашнее задание. Готов раздел «Тепловые явления» 8 класса, 28 уроков.

    исходникиschool-phys-bookJupyter Book

Программирование и машинное обучение

Для тех, кто пишет код в физических исследованиях: от Linux и Git до нейросетей.

  • Разработка и применение ПО в физических исследованиях

    Linux, Python, Git, тестирование, контейнеры, профилирование и оптимизация: как писать надёжный научный код и сопровождать его.

    исходникиsoft-dev-bookmdBook
  • Базовые методы ИИ в физических исследованиях

    Регрессия, классификация, деревья и случайный лес, кластеризация, снижение размерности, нейросети. С практикумом и вопросами для самопроверки.

    исходникиbasic-ml-bookmdBook
  • Рецепты машинного обучения

    Двенадцать коротких тетрадей с примерами обучения моделей scikit-learn на встроенных датасетах: от линейной регрессии до многослойного перцептрона.

    исходникиml-recipe-bookJupyter Book
  • Базовые алгоритмы

    Разборы алгоритмических задач: условие, формат ввода и вывода, решение на Python и Go. Восемь спринтов, от поиска ближайшего нуля до динамического программирования.

Практикум

Каждое задание — репозиторий-шаблон: его достаточно скопировать кнопкой «Use this template».

  • Linux установка системы, процессы и потоки вывода, инструменты командной строки
  • Python эффективный код, цепи Маркова, ревью чужого кода, жизненный цикл ПО
  • Машинное обучение линейная регрессия, логистическая регрессия, k ближайших соседей, нейросеть для классификации, соревнование Kaggle
